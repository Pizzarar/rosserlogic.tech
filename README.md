# rosserlogic.tech

Personal site of Aubrey Rosser: IT operations, development, and the Idle Minds game studio.

Built with [seite](https://seite.sh). Source lives in `personal-site/`; GitHub Actions builds it and deploys to GitHub Pages on every push to `main`.

```
cd personal-site
seite serve      # local preview
seite build      # output in personal-site/dist
```
